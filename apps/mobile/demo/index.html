NOVA Votre copilote personnel pour comprendre vos investissements. Démonstration statique

Les écrans réels de NOVA, avec les données réelles du seed.

Naviguez dans l’application ci-dessous : les chiffres, les actualités, les scores et les réponses de NOVA proviennent de l’API du projet, interrogée avec le compte de démonstration.

Ce que vous voyez. Une capture figée : pas de compte, pas de serveur, pas d’écriture possible. Chaque valeur affichée a été produite par le vrai moteur de scoring, le vrai calcul d’exposition et le vrai générateur de briefing. Ce que vous ne voyez pas. L’application réelle tourne en natif (iOS, Android) sur une API Node et une base PostgreSQL. La marche à suivre pour l’exécuter, ou l’héberger sur votre propre infrastructure, est en bas de page.

L’exécuter pour de vrai

Trois commandes depuis un clone. Sans aucune clé d’API, le produit est entièrement fonctionnel en mode démonstration.

En local

# Node ≥ 20.11, pnpm 10, PostgreSQL 16
pnpm install
pnpm bootstrap   # .env, base, migrations, seed
pnpm dev         # API + application mobile

Scannez le QR code avec Expo Go : l’application détecte l’adresse de la machine qui sert le bundle et joint l’API automatiquement.

Pour obtenir une URL publique

L’API se déploie comme conteneur (infrastructure/Dockerfile.api), avec une base PostgreSQL managée. La cible web se déploie comme site statique. 

# API
docker build -f infrastructure/Dockerfile.api -t nova-api .
# migrations, avant le déploiement du code
pnpm --filter @nova/api exec prisma migrate deploy

# web
pnpm --filter @nova/mobile exec expo export --platform web

Détail des environnements, du pipeline et des points de vigilance : docs/10-deployment.md et docs/09-security.md.

NOVA fournit une information pédagogique et contextuelle. NOVA ne délivre pas de conseil en investissement personnalisé, n’exécute aucune transaction et n’a accès à aucun compte. Les performances passées ne préjugent pas des performances futures.
